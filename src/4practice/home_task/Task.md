# Лабораторная работа: Ветвление процессов в Linux с помощью fork()

## Описание задания
Необходимо разработать программу на языке Си, демонстрирующую параллельную работу родительского и дочернего процессов. Разделение логики процессов должно быть реализовано через вызовы отдельных функций, а не внутри блока main.

---

## Требования к реализации

### 1. Использование макроопределений
Задайте максимальное количество итераций цикла с помощью директивы `#define`:
```c
#define MAX_COUNT 200
```

### 2. Архитектура программы
В коде необходимо объявить и реализовать две функции со следующими прототипами:
* `void ChildProcess(void);` — содержит код, который должен выполнять дочерний процесс.
* `void ParentProcess(void);` — содержит код, который должен выполнять родительский процесс.

### 3. Логика работы функций
Внутри каждой функции требуется организовать цикл со счетчиком, выполняющийся до достижения `MAX_COUNT`. 
* Дочерний процесс на каждой итерации должен выводить строку формата:
  ```c
  printf("This line is from child, value = %d\n", i);
  ```
* В родительском процессе реализуйте аналогичный цикл со своим текстом, чтобы при чтении вывода терминала можно было различить работу двух процессов.

---

## Алгоритм работы функции main
1. Выполнить системный вызов `fork()`.
2. С помощью управляющей конструкции `if` проверить результат вызова:
   * Если вернулось отрицательное значение — вывести сообщение об ошибке (с помощью `perror`) и завершить программу.
   * Если вернулся 0 — вызвать функцию `ChildProcess()`.
   * Если вернулось значение больше нуля — вызвать функцию `ParentProcess()`.
